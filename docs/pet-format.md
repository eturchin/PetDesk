# Формат питомца PetDesk v1

Это собственный JSON-формат PetDesk, не официальный manifest ChatGPT/Codex.

```json
{
  "schemaVersion": 1,
  "id": "sample-pet",
  "name": "Sample pet",
  "spriteSheet": "spritesheet.png",
  "frameWidth": 192,
  "frameHeight": 208,
  "columns": 8,
  "rows": 11,
  "animations": {
    "idle": { "row": 0, "frames": 6, "fps": 8, "loop": true },
    "walkRight": { "row": 1, "frames": 8, "fps": 8, "loop": true },
    "walkLeft": { "row": 2, "frames": 8, "fps": 8, "loop": true },
    "wave": { "row": 3, "frames": 4, "fps": 7, "loop": false },
    "jump": { "row": 4, "frames": 5, "fps": 7, "loop": false }
  }
}
```

## Поля и границы

- `id`: 1–80 ASCII букв, цифр, `-` или `_`; при импорте заменяется внутренним уникальным id. `name`: 1–100 символов без управляющих кодов.
- `spriteSheet`: путь внутри папки с manifest. Подкаталоги разрешены; `../`, абсолютные пути, UNC, ADS, symlink и junction не разрешены.
- `frameWidth`, `frameHeight`: 1–4096. `columns`, `rows`: 1–64. Размер PNG должен **точно** совпадать с произведениями размеров сетки.
- `row`, `startColumn` (по умолчанию 0): нумерация с нуля. `frames`: число подряд идущих кадров в одной строке, минимум 1.
- `fps`: 1–60, по умолчанию 8. `loop`: по умолчанию true.
- `frameDurationsMs`: необязательный массив, по одному значению 16–10000 мс на кадр. Если задан, имеет приоритет над fps. Пример idle известного адаптера: `[280,110,110,140,140,320]`.

Обязательна анимация `idle`. Остальные ключи поведения: `walkLeft`, `walkRight`, `wave`, `jump`. Если нужного ключа нет, отображается idle. Произвольные дополнительные имена допустимы и доступны в списке предпросмотра; FSM самостоятельно использует только известные ключи. Нельзя загружать более 64 анимаций, более 16 мегапикселей atlas/суммарного кэша, изображение с любой стороной более 8192 или файл более 32 МБ. Manifest — до 1 МБ. Нужен статический spritesheet.

## Проверенный адаптер Pets

В доступном локальном каталоге найден реальный PNG **1536×2288** (RGBA): v2, сетка **8×11**, кадр **192×208**. Семантика строк сопоставлена изображению и локальной bundled-документации Pets `create-pet/references/animation-rows.md`. V1 1536×1872 поддерживается тем же расположением первых девяти строк; реального v1-файла в окружении не было, его совместимость здесь проверена только структурными тестами.

| Строка | Ключ PetDesk | Кадры | Длительности, мс |
|---|---|---|---|
| 0 | idle | 6 | 280, 110, 110, 140, 140, 320 |
| 1 | walkRight | 8 | 120 × 7, 220 |
| 2 | walkLeft | 8 | 120 × 7, 220 |
| 3 | wave | 4 | 140 × 3, 280 |
| 4 | jump | 5 | 140 × 4, 280 |
| 5 | failed | 8 | 140 × 7, 240 |
| 6 | waiting | 6 | 150 × 5, 260 |
| 7 | running | 6 | 120 × 5, 220 |
| 8 | review | 6 | 150 × 5, 280 |
| 9–10 | look000.0 … look337.5 | по 1 на направление | неподвижная поза |

Шестнадцать направлений взгляда идут по часовой стрелке с шагом 22,5°; 000° — вверх. Автоопределение по размеру предполагает именно эту раскладку. Если чужое изображение имеет тот же размер с другой раскладкой, используйте явный pet.json.

PNG декодируется штатно через WPF/WIC. WebP принимается только если установленный WIC-кодек способен его декодировать; отсутствие кодека даёт сообщение с предложением использовать PNG. В поставку не добавлен сторонний WebP codec.
