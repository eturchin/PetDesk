# Artwork and user data

The MIT license covers PetDesk code and the original Mochi Cat / Pixel Fox artwork. Their reproducible drawing source is in `tools/PetDesk.AssetBuilder`.

Imported images retain their own copyrights and licenses. Importing a file does not grant redistribution rights. User-provided reference art, settings, themes, pet libraries, logs and local QA records are excluded from the public repository and release payloads.
